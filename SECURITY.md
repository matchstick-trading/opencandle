# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately rather than through a public
GitHub issue or pull request.

Email **hello@matchstick.trading** with a description of the issue, steps to reproduce, and
any relevant logs or proof-of-concept code. We will acknowledge your report and work with you
on a fix and disclosure timeline before any public discussion.

## Supported versions

`opencandle` is pre-1.0. Security fixes are applied to the latest released version on `main`;
there is no separate long-term-support branch at this time.

## Scope

This policy covers the `opencandle` schema, normalization library, and protobuf definitions in
this repository. It does not cover third-party integrations or downstream consumers of the
published package.
